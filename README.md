# Perudo RL

A reinforcement learning project exploring whether an agent can learn to play Perudo (Liar's Dice) from scratch through self-play.

## Project Goals

- Build a functioning Perudo game environment in Python.
- Implement the rules and game mechanics.
- Create an environment suitable for reinforcement learning.
- Train an agent through self-play.
- Eventually play against the trained agent.

## Current Status

🚧 Early development — currently building the Perudo game environment before adding any machine learning.
